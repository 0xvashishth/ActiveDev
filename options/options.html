Server Configuration

Enter the URL of your authentication server. The server handles GitHub App OAuth so that secrets are never stored in the extension.

How to set up

  1. Deploy the authentication server

    Follow the instructions in server/README.md to deploy the server to Render, Railway, Fly.io, or any VPS with HTTPS.

  2. Create a GitHub App

    Go to GitHub Developer Settings → GitHub Apps → New GitHub App

    Set the Callback URL to https://your-server.com/api/auth/callback. Configure Pull requests (Read-only) and Checks (Read-only) permissions.

  3. Configure the server

    Set GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET, and PUBLIC_URL environment variables on your server.

  4. Connect

    Enter your server URL above and click "Login with GitHub".

Security

  • GitHub App credentials are stored only on the server, never in the extension
  • OAuth flow uses CSRF protection via random state parameter
  • Access token is transmitted over HTTPS and stored in chrome.storage.local
  • Server uses Helmet for security headers and rate limiting
  • GitHub App permissions are scoped to read-only Pull requests and Checks
