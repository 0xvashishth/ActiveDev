ActiveDev

GitHub Review Reminder

Connected as

Authentication

Connect your GitHub account to start getting review notifications. The OAuth app requests read-only access to your pull requests, checks, and organization membership.

How it works

  1. Login with GitHub

    Authorize the ActiveDev OAuth App to get an access token.

  2. Grant access

    The OAuth app requests read-only access to your pull requests, checks, and organization data.

  3. Get notified

    You'll receive notifications when you're added as a reviewer or when someone reviews your PRs.
