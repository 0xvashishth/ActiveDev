Authentication

Connect your GitHub account to start getting review notifications. ActiveDev requests the repo, read:user and read:org scopes so it can see pull requests in private repositories and in the organizations you belong to. ActiveDev only ever reads data; GitHub has no read-only scope for private repositories, so repo is required.

Organization access

Organizations can block third-party OAuth apps or require SAML single sign-on. When that happens GitHub silently hides their pull requests, so they will not show up here until access is granted.

      Notes & todos

      Your daily todos and notes (popup → Notes tab) are stored only in this browser profile. They are kept when you disconnect GitHub, but are lost if the extension is removed — export a backup to keep them or move them to another computer.

      How it works

      1. Login with GitHub

        Authorize the ActiveDev OAuth App. On the GitHub consent screen, use Grant / Request for each organization whose pull requests you want to see.

      2. Background checks

        ActiveDev periodically fetches PRs awaiting your review (directly or via your teams) and your own open PRs, across all accessible repositories and organizations.

      3. Get notified

        You'll receive notifications when you're added as a reviewer or when someone reviews your PRs. The popup shows who already reviewed, unresolved conversations, CI status and merge conflicts.
