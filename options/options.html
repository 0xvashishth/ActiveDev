GitHub OAuth App Configuration

To use this extension, you need to create a GitHub OAuth App and enter its credentials below.

Add this URL to your GitHub OAuth App settings under "Authorization callback URL".

How to set up

  1. Create an OAuth App

    Go to GitHub Developer Settings → OAuth Apps → New OAuth App

  2. Configure the app

    Set "Application name" to "ActiveDev". Set "Authorization callback URL" to the URL shown above (copy it from the field).

  3. Get credentials

    After creating the app, copy the "Client ID" and generate a "Client Secret". Paste them in the fields above.

  4. Authenticate

    Click "Save & Authenticate" and authorize the extension to access your GitHub account.

Permissions Requested

  • repo - Access to your repositories (needed to read PRs and check statuses)
  • read:user - Read your profile information
